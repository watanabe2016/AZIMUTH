# AZIMUTH · 方位角

AZIMUTH 是免费的 Windows 桌面学习工具，用于整理用户自行导入的地面站题卡、练习和查看 API 生成的参考解答。发布版不附带作者整理的题库或题库答案。

## 导入题卡

进入「题库题卡」，点击页面上方的「导入题卡」，可以一次选择多个 PDF 或图片，也可以把文件拖到页面的导入区域。PDF 先预览选页，再识别并校对文字；完成后显示成功、跳过、失败和识别提醒的汇总。相同文件会按 SHA-256 摘要跳过。

筛选摘要始终显示当前条件和题数；可直接清除条件。预览支持「整页适配」「适合宽度」和缩放；损坏或缺失的图片会显示重试入口。

题库快捷键：Ctrl+O 导入题卡，Ctrl+F 搜索，Alt+左／右键翻题，Ctrl+Enter 打开练习，Ctrl+D 标记或取消已做。编辑文本时不会触发标记已做。

设置按外观主题、计时声音、题库判分、视觉 API、维护支持分组；费用估算默认折叠。导入人物主题包后，桌面时钟人物列表会增加对应人物，并提供预览；时钟人物可独立于页面主题选择。

打开「更多 → 已导入文件」可以查看文件名、类型、大小、导入时间和题卡数；支持多选删除或清空。删除前会再次确认，并同步删除来源文件对应的题卡与图片。

## 配置 API 解题

打开「设置 → 视觉 API」，选择 OpenAI、DeepSeek 或其他兼容 OpenAI Chat Completions 且支持图片输入的服务，填写 HTTPS API 地址、模型名称和 API Key。API Key 在 Windows 上以当前用户保护的形式保存在本机。

在导入题卡的「参考答案」窗口点「解题」后，软件会把题卡图片和校对过的条件发给所选视觉模型。模型直接审题并生成参考答案；收到流式回答时会逐段显示，结束后再完整排版 Markdown、公式、表格、代码和图片。可复制、展开或收起答案；请求中可点同一按钮中止当前 API 响应。若模型无法返回航图，文字答案仍会保留。所有模型答案都需要用户对照原题复核。

费用与余额显示规则：

- 服务商返回 token 用量时，软件按设置页填写的模型单价估算本次花费，并累计本机估算金额。
- DeepSeek 可用余额会尝试从服务商查询；其他服务商若没有通用余额接口，可在设置中填写本地预算，用于估算剩余金额。
- 服务商没有返回用量时，软件会明确说明无法估算；本地估值不是服务商的账单。

**免责声明：本软件本身完全免费，不收取任何费用。使用 API 解题时产生的费用由 API 服务商收取，与本软件作者无关。请自行确认 API 服务商的计费规则并承担相应费用。** 首次调用 API 前会再次显示此声明。

## 数据与隐私

应用只会在用户主动点击「解题」后上传当前题卡。题卡、OCR 结果、导入来源清单和练习数据保存在本机；软件不内置作者整理的题库、答案、教师样本或原题图片。

绿色版通常将 config.json、data、notes 和 logs 保存在程序目录；若该目录不可写，会回落到用户目录。data/bank 存放用户导入的题卡。迁移到新版本时只复制这些用户数据，不要用旧版内部运行资源覆盖新版运行资源。

## 运行与构建

Windows 10/11 64 位。运行完整发布目录中的「启动 AZIMUTH」或 AZIMUTH.exe，请保留同目录的运行资源文件夹。开发环境可运行 python app/main.py，打包命令为 python build/build_release.py。

五个板块各接入 50 项动效触点，展开和关闭采用平滑曲线，支持中途反向操作、隐藏停止和减少动画设置。新增自定义计时、练习记录、教学暂停与步进、风力调节及 A4 教学预览。题卡识别所需 OCR、PDF 解析与公式排版资源随程序发布；API 解题需要互联网连接及服务商 API Key。
