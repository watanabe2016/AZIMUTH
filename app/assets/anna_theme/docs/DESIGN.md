# 杏菜的青春封面 · 设计交付规范
版本 2.0.0。依据用户选定的青春励志小说封面式学习首页与角色修正版。交付对象：AZIMUTH 的 Web 前端和 PySide6/Qt 界面。

## 视觉依据
以 screens/light/home.png 为青春励志小说封面式主视觉；其余效果图展示五个板块在浅色、深色下的完整状态。
人物是八奈见杏菜：及肩蓬松蓝发、头顶翘发、无发饰、白短袖衬衫、蓝黄蓝黄四枚蝴蝶结。原先长发、水手领、红领结版本已弃用。
人物在首页主视觉中较大，业务页限于标题区。内容面板不叠加人物或复杂底图。
生成效果图若有头发越过标题栏、细小文字偏差，以本文和真实组件为准：标题栏始终独立，人物容器必须 overflow:hidden。

## 页面与布局
基准 1600×1000；标题栏44，侧栏232，内容间距20，页面内边距28。正文16/1.65，辅助13，分节24，页标题36，首页标题58，计时112。内页标题区建议144，上限180，低高度窗口压缩至112；人物不挤占内容。
题库左右约58:42；原题图白底保留；文本文字与数值必须从现有题库读取，不使用渲染图内重绘题目。
限时模拟左右约55:45；阅题/作答/完成只表示阶段，计时器依旧由业务层驱动；正式计时期间装饰保持静止。
教学保持三角形的1顶、2右下、3左下编号；八个图形素材是界面示意，正式教学以项目业务数据和题卡为准。
设置中“应用主题”与“显示外观”独立保存，浅色/深色/跟随系统只改变主题色表。
不新增虚构统计。首页440、16、1仅为对齐截图的样例值。

## 颜色与状态
tokens/theme.json 是颜色唯一依据；styles/theme.css 是 Web 可直接加载的变量与基础组件。
主按钮均蓝底白字；深色链接使用浅蓝。珊瑚用于小标题/辅助类别，错误使用 danger 并配文字，不仅靠颜色表达。
输入框与非填充按钮使用 controlBorder；大面积分隔线使用 border。
hover、focus-visible、disabled、selected、invalid 均已覆盖。键盘焦点3px，控件最小高度44px。计时数字使用等宽数字。
图标主规格24×24、线宽1.8。currentColor 版本需内联使用；外部 img 或 QIcon 使用 light/dark 下的定色文件。
不将整张效果图用作界面背景，不把任何可交互文字烘焙进素材。

## 字体
随包提供 Noto Sans SC 可变字体与 OFL 许可证，字重100–900。Web 自动从本地加载；Qt 通过 QFontDatabase.addApplicationFont 注册。
回退 Microsoft YaHei / Segoe UI。不分发系统字体。字形最终以打包字体为准，不追求图像生成器中不可复现的标题字形。
字体许可只适用于字体，不延伸到角色或产品品牌。

## 素材组合
assets/characters/anna-hero.png：透明角色主素材，首页用 object-fit:contain，右侧放置，头像亦可用 CSS 裁切，不需重绘人物。
assets/backgrounds/sky-light.png 与 sky-dark.png：无文字、无人物的背景。
assets/brand：从当前项目复制的真实 AZIMUTH 图标，正式使用此文件，避免沿用渲染图里偶发重绘的图标。
assets/figures：可编辑SVG图形、首页三张示意插画、计时环、蓝黄领结装饰、主题缩略图。
assets/icons：通用24px SVG图标及浅深定色版本。

## 适配与接入边界
当前产品为 PySide6 + Qt WebEngine 混合界面。CSS供Web使用，QSS供Qt接入参考；效果图和本包不是已经安装到软件的皮肤。
QSS使用 annaTheme、annaRole 动态属性，不依赖现有对象名；参照 INTEGRATION.md 映射后应用。
尺寸小于1100宽时先收窄侧栏，卡片允许换行；题图与文字区应允许独立滚动。实际业务适配与运行回归由接入阶段完成。
