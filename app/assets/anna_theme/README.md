# 杏菜的青春封面 · 前端素材包 v2
打开 preview.html 查看五个板块 × 浅色/深色共10张；采用小说封面式青春编辑风效果图。
打开 components.html 查看真实字体、独立素材和可切换浅深色的基础组件。
两者无需安装依赖，可直接用浏览器打开。

- screens/：10张页面设计效果图，供比对，不作为界面贴图。
- assets/characters/：独立透明底人物PNG。
- assets/backgrounds/：浅深场景背景。
- assets/brand/：原项目AZIMUTH图标。
- assets/icons/：原生SVG图标，含可内联与浅深定色版本。
- assets/figures/：8种教学示意图、首页三张装饰插画、计时环与主题缩略图。
- assets/fonts/：Noto Sans SC可变字体及OFL许可。
- tokens/theme.json：完整颜色、字号、间距与尺寸。
- styles/：可直接引用的CSS，以及Qt浅深QSS接入参考。
- docs/：设计与接入说明。
- provenance/：生成提示、参考来源与文件清单。
- manifest.json：资源用途、尺寸、大小、校验值；verification.json：交付检查结果。

本包是设计素材与接入基底，不是已安装的应用皮肤；未修改现有程序或学习数据。
人物与场景经内置 imagegen 生成；图标和教学示意为原生SVG；字体来源Google Fonts，产品图标来自本项目。
